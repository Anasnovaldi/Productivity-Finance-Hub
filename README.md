## 📌 Tentang Proyek
**Tabungan Tracker** adalah aplikasi berbasis web sederhana yang dirancang untuk membantu mencatat pemasukan keuangan secara *real-time*. Aplikasi ini memisahkan pencatatan antara uang fisik (*Cash*) dan uang di dompet digital (*Digital*), sehingga total aset dapat terpantau dengan jelas.

Proyek ini dibangun murni menggunakan **Vanilla JavaScript** (tanpa *framework*) untuk melatih manipulasi DOM (Document Object Model) dan logika perhitungan data secara dinamis.

## ✨ Fitur Unggulan
- **Dual Wallet System:** Memisahkan kalkulasi total saldo berdasarkan kategori *Cash* atau *Digital*.
- **Validasi Input Pintar:** Mencegah pengguna memasukkan form kosong atau nominal angka di bawah nol (minus).
- **Interactive History List:** Setiap uang yang ditabung akan memunculkan riwayat baru dengan indikator warna yang intuitif (Hijau untuk Cash, Biru untuk Digital).
- **Auto-Calculate:** Total saldo akan menjumlahkan dirinya sendiri secara otomatis setiap kali ada entri baru.
